# AKC미니게임

Windows용 크기 조절 가능한 투명 창 미니게임 모음입니다. 로그인 후 `게임 시작`(또는 Space)을 누르면 게임 목록이 나오고, 고른 게임이 시작됩니다. 현재 목록에는 **똥 피하기**, **키보드 리듬**, **뺨때리기(2인 대전)** 3개가 있습니다. 별도 서버 없이 로컬 계정과 게임 기록을 JSON으로 저장합니다.

## 실행

- 이 폴더의 `실행.cmd`를 더블 클릭합니다. 빌드된 앱이 있으면 즉시 실행합니다.
- GitHub [최신 배포](https://github.com/poyoyoyng/DDongVoid/releases/latest)의 `DDongVoid-win-x64.zip`을 전체 압축 해제한 뒤 `DDongVoid.exe`를 실행합니다. 업데이트 도우미를 포함한 파일 8개를 모두 유지해야 합니다. `D:\` 같은 드라이브 최상위나 `Program Files` 대신 `D:\AKC미니게임`처럼 쓰기 권한이 있는 폴더를 만들어 압축을 풀어야 자동 업데이트가 됩니다.
- 로컬 배포 빌드는 `artifacts/release/package/DDongVoid.exe`입니다. 개발 명령으로 빌드한 실행 파일은 `bin/Release/net10.0-windows`에 생성됩니다.
- 개발 및 최초 빌드: Windows와 .NET 10 SDK가 필요합니다. 빌드된 앱 실행에는 .NET 10 Desktop Runtime이 필요합니다.

```powershell
dotnet build DDongVoid.csproj -c Release
dotnet run --project DDongVoid.csproj -c Release
# 업데이트 도우미를 포함한 배포 ZIP 생성
./scripts/Publish-Release.ps1 -Version 1.0.0
```

## 플레이

| 조작 | 동작 |
|---|---|
| ← / → 또는 A / D | 좌우 이동 |
| Space | 시작, 일시정지, 계속하기 |
| Esc | 일시정지, 계속하기, 메뉴에서 돌아가기 |
| F2 | 설정 열기 / 닫고 게임으로 복귀 |
| Ctrl + Shift + Space | 앱 숨기기 / 다시 표시 (다른 창에서도 사용 가능) |
| 상단 바 드래그 | 창 이동 |
| 메인 메뉴 패널의 글자 / 빈 공간 드래그 | 창 이동 (로그인·설정 패널에서도 가능) |
| 메뉴 패널 오른쪽 위 ✕ | 앱 종료 |
| Alt + 캐릭터 드래그 | 투명 모드에서 창 이동 |
| 테두리 / 모서리 드래그 | 창 크기 조절 |

창에서 포커스가 벗어나거나 창을 이동·최소화·숨기면 자동 일시정지합니다. 다시 돌아오면 `계속하기`를 누릅니다. 단축키가 다른 앱에서 사용 중이면 숨기기 버튼은 최소화로 작동하며 안내를 표시합니다.

점수는 **생존 1초당 10점 + 화면 아래까지 피한 똥 1개당 25점**입니다. 생존 시간이 늘수록 기존에 떨어지던 똥까지 점점 빨라지고 새로운 똥도 더 자주 생성됩니다. 똥의 기본 낙하 속도와 생성 빈도는 기준값보다 15% 높습니다(`GameEngine.Difficulty`). 낙하 속도는 시작 대비 30초에 약 1.5배, 60초에 약 2배, 180초 이후 최대 4배입니다. 기본 생성 간격은 약 0.61초에서 최소 0.104초까지 줄어들며 실제 생성 간격에는 ±20%의 무작위 변동을 줍니다. 난이도 레벨은 12초마다 올라갑니다. 일시정지 중에는 생존 시간과 난이도가 증가하지 않으며, 새 게임을 시작하면 처음 난이도로 돌아갑니다.

일시정지 메뉴의 **그만하기 · 메인 메뉴로**를 누르면 로그인 상태를 유지한 채 이번 판을 끝내고 시작 화면으로 돌아갑니다. 그만하거나 다시 시작한 판은 기록에 저장하지 않습니다. 똥에 맞아 끝난 판은 로그인한 계정의 기록으로 자동 저장합니다. 게임은 로그인해야 시작할 수 있으며, 로그인하지 않은 상태에서 시작하면 로그인 화면으로 이동합니다.

## 키보드 리듬

화면이 왼손·오른손 2개 라인으로 나뉘고, 키 글자(S·D·K·L)가 적힌 블록이 내려옵니다. 블록이 아래 판정선에 닿는 순간 그 키를 누릅니다. 양손 라인에 블록이 동시에 내려오기도 하며, 이때는 두 키를 함께 누릅니다. 동시 블록 비율은 처음 20%에서 시간이 지날수록 늘어 최대 45%입니다.

| 라인 | 키 |
|---|---|
| 왼손 | S · D |
| 오른손 | K · L |

- 판정: 판정선과의 차이 0.05초 이내 **PERFECT**(300점), 0.1초 이내 **GREAT**(200점), 0.16초 이내 **GOOD**(100점). 놓치면 **MISS**입니다.
- 콤보: 연속으로 맞히면 콤보가 쌓이고, 판정마다 콤보 × 2점(최대 200점)을 더 받습니다. MISS가 나면 콤보가 0이 됩니다.
- 라이프: 100%에서 시작해 MISS마다 10% 줄고, PERFECT는 2%, GREAT는 1% 회복합니다. 0%가 되면 끝납니다.
- 리듬 패턴: 정박뿐 아니라 반 박자 당기거나 미는 엇박, 빠르게 두 번 치는 따닥, 3~5개를 이어 치는 연속 패턴이 무작위로 섞여 나옵니다. 시간이 지날수록 따닥·연속·엇박 비율이 늘어나며, 연속 블록 사이 간격은 최소 0.12초입니다.
- 무작위: 블록의 라인·키·간격은 판마다 새 무작위 시드로 정해 실행할 때마다, 한 판 더 할 때마다 다른 패턴이 나옵니다.
- 속도: 시간이 지날수록 블록이 계속 빨라집니다. 시작 대비 60초에 2배, 120초에 3배, 약 136초 이후 최대 약 3.3배이며 현재 배속은 화면 위쪽에 `SPEED ×1.0`처럼 표시합니다. 블록 간격도 점점 짧아집니다.
- 판정 범위 밖에서 누른 키는 무시하므로 미리 누른다고 감점되지 않습니다. 한글·영문 입력 상태와 관계없이 같은 자리의 키로 인식합니다.
- 완료한 판의 점수는 저장 폴더의 `ddongvoid-rhythm.json`에 기록하며, **랭킹 보기 → 키보드 리듬**에서 계정별 최고 점수를 비교합니다. 이전 버전에서 이 PC에만 저장한 최고 점수는 그대로 유지되며, 공유 랭킹에는 업데이트 후 완료한 판부터 반영됩니다. 저장에 실패하면 결과 화면에서 재시도할 수 있습니다.

## 뺨때리기 (2인 대전)

같은 저장 폴더를 쓰는 두 사람이 1:1 턴제로 겨룹니다. 게임 목록에서 **뺨때리기**를 고른 뒤 `방 만들기`로 방을 열고, 상대는 방 목록에서 그 방에 참가합니다. 두 사람 모두 `준비 완료`를 누르면 시작합니다. 동시에 접속할 필요 없이 서로 시간 날 때 버튼을 눌러 진행할 수 있습니다.

한 사람이 방을 여러 개 만들거나 2~3개 이상의 방에 동시에 참가할 수 있습니다. `내가 참가한 방` 목록에 방마다 별도의 항목이 생기며, 방 번호·참가자·라운드·선택 대기 상태로 구분합니다. 대기실에서도 `방 목록으로 · 참가 유지`를 눌러 다른 방을 만들거나 참가할 수 있고, 각 방의 준비 상태·체력·기력·선택한 행동은 독립적으로 유지됩니다. `방 나가기`는 해당 대기실이나 종료한 방에서 실제로 나갈 때 사용합니다.

- 체력 5, 기본 공격력 1, 기는 최대 3개까지 모읍니다. 시작할 때 기는 0개입니다.
- 라운드마다 공격과 수비를 번갈아 합니다. 방을 만든 사람(P1)이 1라운드 공격, 참가한 사람(P2)이 수비이고 다음 라운드에 바뀝니다.
- 두 사람은 각자 비공개로 하나를 고릅니다. 상대 화면에는 `입력 완료 ✓` 여부만 보이고, 둘 다 고르면 결과가 나옵니다. 한 사람이 먼저 고른 행동은 상대가 나중에 선택할 때까지 보관합니다.
  - 공격: **상단·중단·하단** 중 한 곳을 때리거나 **기 모으기**(+1)
  - 수비: **상단·중단·하단** 중 한 곳을 막거나 **기 모으기**(+1, 그 턴은 막지 못함)
- **기본공격**은 기 소모 없이 피해 1, **강한 뺨**은 기 1개를 소모해 피해 2, **필살뺨**은 기 3개를 소모해 피해 5를 줍니다. 기본공격은 기가 0개여도 가능합니다. 기가 3개면 더 모을 수 없습니다.
- 방어는 기력과 관계없이 항상 선택할 수 있으며 기를 소모하지 않습니다. 수비가 때린 곳과 같은 곳을 막으면 피해가 없습니다. 다른 곳을 막았거나 기를 모았으면 그대로 맞습니다. 스킬이 막혀도 공격자가 쓴 기는 돌아오지 않습니다.
- 상대 체력을 0으로 만들면 승리합니다. 결과 화면에서 둘 다 `다시 하기 · 준비 완료`를 누르면 체력·기를 초기화하고 다시 시작합니다.
- 방 목록으로 돌아가거나 앱을 종료·로그아웃해도 대전과 선택한 행동은 유지됩니다. 같은 저장 폴더와 계정으로 로그인한 뒤 방 목록의 `이어하기`를 누르면 체력·기력·현재 턴을 그대로 이어갑니다. 다른 방을 만들거나 참가해도 기존 대전은 유지됩니다.
- 중도 종료하려면 두 사람 모두 `포기하기`를 눌러야 합니다. 한 사람만 포기하면 요청 상태로 대기하며, `포기 요청 취소`를 누르면 기존 선택을 유지한 채 계속 진행할 수 있습니다. 서로 다른 시간에 포기해도 되며, 양쪽 포기로 종료한 판은 승패 기록에 넣지 않습니다.

대전 상태는 저장 폴더의 **`ddongvoid-slap.json`** 에 보관하며, 두 PC가 1초마다 모든 방을 함께 읽어 참가자·준비·시작·턴 상태를 맞춥니다. 방에 다시 들어오면 자동 조회를 재시작하고 즉시 최신 상태를 확인합니다. 방 목록과 대전 화면에 같은 방 번호를 표시하므로 양쪽이 같은 방에 참가했는지 확인할 수 있습니다. 방마다 다음 정보를 기록합니다.

| 필드 | 뜻 |
|---|---|
| `Players[].Id` | 참가 중인 아이디 (최대 2명, 0번이 P1) |
| `Players[].Ready` | 준비 완료 여부 |
| `Status` / `Started` | `Waiting`(대기) · `Playing`(진행 중) · `Finished`(종료) / 시작 여부 |
| `Players[].Submitted` | 이번 턴에 입력했는지 (`Choice`에 고른 행동) |
| `Players[].Hp` · `Gauge` | 체력 · 기 |
| `Round` · `AttackerId` · `DefenderId` | 현재 라운드와 공격·수비 |
| `LastResult` | 직전 라운드 결과 (행동, 막았는지, 피해) |
| `Winner` · `EndReason` | 승자와 종료 사유 (상호 포기는 승자 없음) |
| `Players[].GaveUp` | 각 참가자의 포기 요청 여부 |

상대 체력을 0으로 만들어 완료한 대전의 승자·패자를 `ddongvoid-slap.json`의 `Matches`에 보관합니다. **랭킹 보기 → 뺨때리기**에서 누적 **승·패**를 함께 표시하고 **승수가 많은 순서**로 정렬합니다. 승수가 같으면 패수와 관계없이 공동 순위이며, 같은 순위 안에서는 아이디순으로 표시합니다. 재대전과 종료한 방 삭제 후에도 누적 기록을 유지합니다. 업데이트 전 대전은 누적 기록이 없어 반영되지 않습니다. 개인 기록 화면은 똥 피하기 기록을 표시합니다.

접속 시간에 따른 자동 종료나 방 삭제는 없습니다. 파일이 손상되면 대전·승패 기록을 보호하기 위해 덮어쓰지 않고 오류를 표시하므로 백업을 복원해 주세요. 상대가 고른 행동도 파일에는 들어 있으므로 이 파일을 직접 열어 보면 미리 알 수 있습니다. 친선 게임용입니다. 이전 버전의 자동 기권·방 정리가 작동하지 않도록 같은 저장 폴더를 쓰는 모든 PC를 최신 버전으로 업데이트해 주세요.

## 투명 창과 설정

메인 메뉴의 `설정` 버튼, 하단 `설정`, 또는 F2로 열어 다음을 변경합니다.

- **PNG 배경 제거처럼 완전 투명 · UI 숨기기**: 기본 켜짐입니다. 게임 배경의 알파값을 정확히 0으로 만들고 점수판·상단 바·하단 바·외곽선을 숨깁니다. 플레이 중에는 캐릭터와 떨어지는 똥만 보입니다. 메뉴는 필요할 때 F2로 열고 닫습니다.
- **배경 불투명도**: 완전 투명 설정을 해제했을 때 배경 농도를 조절합니다. 캐릭터와 똥은 선명하게 유지합니다.
- **캐릭터 알파 / 떨어지는 똥 · 리듬 블록 알파**: 각각 0~100%로 조절하며 즉시 적용합니다. 기본값은 캐릭터 80%, 똥·리듬 블록 65%입니다. 0%에서는 해당 오브젝트가 보이지 않지만 게임 판정은 유지됩니다.
- **투명 모드에서 작은 점수만 표시**: 기본 꺼짐입니다. 필요하면 작은 점수를 켜고 알파값을 별도로 조절합니다. 기본 알파는 25%입니다.
- **항상 다른 창 위에 표시**: 다른 창 위에 게임을 띄웁니다.
- **창 크기 설정 모드**: 투명 모드여도 창 전체 영역을 반투명 배경과 점선 테두리로 보여 줍니다. 테두리·모서리를 드래그해 가로·세로를 맞추고, 안쪽을 드래그하면 창을 옮깁니다. 현재 크기가 가운데에 표시됩니다. `이 크기로 저장`(Enter·F2)으로 저장하고, `취소`(Esc)를 누르면 원래 크기와 위치로 돌아갑니다.
- **작은 창 / 기본 창**: 360 × 440 또는 480 × 740 크기로 바꿉니다. 투명 모드에서는 최소 300 × 320까지 줄일 수 있습니다.
- 마지막 창 크기는 `settings.json`에 저장되어 다음 실행 때 그대로 열립니다.
- **저장 폴더 선택**: 계정과 기록을 저장할 폴더를 직접 선택합니다.

투명한 빈 영역에서는 아래 창을 클릭할 수 있습니다. 아래 창을 클릭하면 게임이 일시정지하므로, 플레이는 게임 창에 포커스를 둔 상태에서 키보드로 합니다. 입력을 숨기거나 다른 앱의 입력을 가로채는 기능은 없습니다.

## 계정과 기록 저장

1. 기본 저장 폴더는 `\\192.168.0.120\SW Team\팀원\최지운\DD`입니다. 다른 폴더는 `설정 → 저장 폴더 선택`에서 지정합니다.
2. `로그인 → 처음이에요 · 회원가입`에서 아이디·비밀번호·비밀번호 확인을 입력합니다.
3. 회원가입하면 자동 로그인됩니다. 이후에는 같은 저장 폴더의 계정으로 로그인합니다.
4. `기록`에서 현재 계정의 최고 점수·플레이 횟수·최장 생존 시간과 최근 기록을 봅니다.
5. 메인 메뉴의 **랭킹 보기**에서 **똥 피하기 / 키보드 리듬 / 뺨때리기**를 선택합니다. 똥 피하기·리듬은 아이디별 최고 점수, 뺨때리기는 누적 승수로 비교하며 승·패를 함께 표시합니다. 로그인하지 않아도 조회할 수 있습니다. 같은 점수·승수는 공동 순위(1위·1위·3위)로 표시하며 로그인한 계정의 행과 내 순위를 구분해 보여줍니다. 인원이 많으면 목록 위에서 **마우스 휠**로 아래 기록까지 볼 수 있습니다. `새로고침`으로 선택한 게임의 최신 기록을 불러옵니다.

아이디는 한글·영문·숫자·`_`·`-` 3~24자, 비밀번호는 1~128자입니다. 아이디의 영문 대소문자는 구분하지 않고 비밀번호는 구분합니다. 로그인 상태는 PC별 설정 파일에 유지되어 앱을 다시 실행하면 자동으로 로그인합니다. 설정 파일에는 비밀번호나 비밀번호 해시가 아닌 세션 확인용 값만 저장합니다. 로그아웃하면 저장된 로그인이 지워지고, 저장 폴더를 바꾸면 해당 폴더의 계정으로 다시 로그인해야 합니다.

선택한 폴더의 **`ddongvoid.json`** 하나에 계정과 기록을 보관합니다. 비밀번호 원문 대신 계정별 무작위 salt와 PBKDF2-SHA256 해시(210,000회)를 저장합니다. 로컬 파일 기반이므로 파일에 접근할 수 있는 사람은 기록을 수정할 수 있으며 온라인 인증·순위 시스템은 아닙니다.

계정마다 `BestScore`에 최고 점수를 함께 저장합니다. 게임 종료 후 점수가 기존 최고 점수보다 높을 때만 갱신합니다. 이전 버전의 JSON도 사용할 수 있으며, 기존 플레이 기록으로 최고 점수를 복원하고 랭킹을 처음 열거나 다음 기록을 저장할 때 JSON에 반영합니다. 아직 한 판도 완료하지 않은 계정은 랭킹에 포함하지 않습니다.

기본 저장 위치는 `\\192.168.0.120\SW Team\팀원\최지운\DD\ddongvoid.json`, 설정 파일은 `%LOCALAPPDATA%/DDongVoid/settings.json`입니다. 기존에 직접 선택한 저장 폴더가 있으면 그 설정을 우선 사용합니다. 실행 파일에 `--portable` 옵션을 전달하면 설정 파일만 실행 파일 옆의 `settings.json`을 사용하며 계정·기록의 기본 경로는 동일한 공유 폴더입니다. 공유 폴더가 연결되지 않았거나 쓰기 권한이 없으면 계정·기록 저장 시 오류를 표시하며 로컬 폴더에 대신 저장하지 않습니다. 저장된 로그인이 있으면 게임 창을 연 뒤 백그라운드에서 공유 폴더로 확인하며, 연결되지 않으면 안내를 표시하고 게임 시작 시 다시 확인합니다.

저장 폴더를 바꾸면 로그아웃되며 기존 데이터는 원래 폴더에 보존합니다. 기존 파일은 자동 이동하지 않습니다. 해당 폴더를 다시 선택하면 원래 계정과 기록을 사용할 수 있습니다. 다른 PC로 옮길 때는 앱을 종료하고 JSON 파일을 복사하세요.

손상되거나 지원하지 않는 JSON은 덮어쓰지 않고 오류를 표시합니다. 게임 기록 저장 실패 시 결과 화면에서 재시도할 수 있습니다. 파일은 임시 파일 작성 후 교체하고, 같은 PC의 실행 창은 이름 있는 뮤텍스, 여러 PC의 공유 폴더 접근은 `.ddongvoid.lock` 파일의 배타적 잠금으로 보호합니다. 동시 저장 보호를 받으려면 참여하는 PC가 모두 최신 버전을 사용해야 합니다. 잠금 파일은 정상적으로 남아 있는 파일이며 지우지 않아도 됩니다.

## 자동 업데이트와 GitHub 배포

`main` 브랜치에 푸시하면 GitHub Actions가 검증 후 `1.0.<실행번호>` 버전의 Windows x64 ZIP을 만들어 GitHub Releases에 게시합니다. 검증·빌드가 실패하면 새 배포를 게시하지 않습니다. 다른 브랜치의 푸시는 배포하지 않습니다. 작업은 Actions 화면의 `Build and release`에서 확인할 수 있으며 수동 실행도 가능합니다.

게임은 실행 시와 실행 중 15분마다 최신 정식 배포를 확인합니다. 새 버전이 있으면 **업데이트가 있습니다. 업데이트하시겠습니까?** 창을 표시합니다. 플레이 중이거나 저장하지 못한 기록이 있으면 안내를 미루고 다음 메뉴 화면에서 표시합니다. 거절한 버전은 같은 실행 중 자동으로 반복 안내하지 않습니다. `설정 → 업데이트 확인`으로 다시 확인할 수 있습니다. 인터넷 연결 실패는 게임 플레이를 막지 않습니다.

동의하면 GitHub의 SHA-256과 다운로드 크기, ZIP 파일 목록, 어셈블리 버전을 검증합니다. 임시 폴더의 업데이트 도우미가 게임 종료를 기다린 뒤 실행 파일 8개만 교체하고 재실행합니다. 중간 교체 실패 시 원래 파일로 복원합니다. JSON 계정·기록, 공유 폴더 설정, `settings.json`은 업데이트에 포함하거나 덮어쓰지 않습니다. 게임 폴더에 쓰기 권한이 필요합니다.

업데이트 기능이 없는 이전 배포를 사용 중인 PC는 **최초 한 번 최신 ZIP 전체로 교체**해야 합니다. 이후부터는 게임 안의 안내로 업데이트할 수 있습니다. 새 ZIP에는 게임 파일 4개와 `DDongVoid.Updater` 파일 4개, 실행 배치 및 안내문이 포함됩니다. 배포에는 .NET 10 Desktop Runtime이 필요합니다. 사용자별 설정이나 계정 JSON은 Git과 ZIP에 포함하지 않습니다.

구현 참고: [GitHub Releases API](https://docs.github.com/en/rest/releases/releases), [GitHub Actions 워크플로](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax).
