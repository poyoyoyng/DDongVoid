# 포요용의 미니게임천국

브라우저에서 똥 피하기, 키보드 리듬, 맞짱, 차오차오, 원카드, 야추, 오목, 섯다, 사보타지를 플레이할 수 있습니다. Windows 앱은 저장소 루트의 `실행.cmd`로 계속 실행합니다. 웹은 자체 계정과 랭킹을 사용하고 Windows 앱은 기존 JSON 저장 폴더를 사용합니다.

웹의 **대기방**에서 맞짱, 차오차오, 원카드, 야추, 오목, 섯다, 사보타지 방을 한 번에 확인할 수 있습니다. **방 만들기**에서 게임과 제목을 지정하면 방이 목록에 올라갑니다.
대기방에서는 로그인한 이용자와 대화할 수 있고, 게임방에서는 참가자와 관전자가 함께 대화할 수 있습니다. 각 채팅창은 최근 메시지 50개를 보여 줍니다.

**키보드 리듬**은 Windows 앱과 같은 규칙입니다. 왼손(S·D)·오른손(K·L) 두 라인에 내려오는 블록을 판정선에서 누르고, PERFECT·GREAT·GOOD 판정과 콤보로 점수를 얻습니다. MISS마다 라이프가 25% 줄어 0%가 되면(MISS 4번) 끝나며, 모바일에서는 화면 아래 S D K L 버튼으로 칩니다. 웹 기록은 웹 랭킹에만 올라갑니다.

**오목**은 15×15 판에서 렌주룰(RIF)로 둡니다. 흑이 먼저 두고 정확히 다섯 개를 이어야 이기며, 흑의 3-3·4-4·장목은 금수라 그 자리에 둘 수 없습니다(판에 × 표시). 백은 제한이 없고 장목도 승리입니다. 흑과 백은 같은 방에서 한 판씩 번갈아 맡고, 첫 판은 P1이 흑입니다.

**섯다**는 화투 20장(1~10월 두 장씩)으로 2~4명이 하는 2장 섯다입니다. 판마다 모두 기본 판돈 1만원을 내고, 한 장을 받아 베팅하고 한 장을 더 받아 다시 베팅한 뒤 남은 사람끼리 족보를 비교합니다. 베팅은 다이·체크·콜·삥(1만원)·따당(앞 베팅의 2배)·하프(콜 후 판돈의 절반)이고, 30초 안에 고르지 않으면 체크할 수 있을 땐 체크, 아니면 다이입니다. 광땡·땡·알리~세륙·끗 순이며 암행어사(13·18광땡 잡기), 땡잡이(1~9땡 잡기), 구사·멍텅구리 구사(재경기)가 있습니다. 족보가 같으면 판돈을 나눕니다. 한 판에 걸 수 있는 돈은 그 판 참가자 중 가장 적은 잔액까지입니다. 판 도중 관전석으로 이동하면 다이로 처리하고, 그 자리는 판이 끝날 때까지 비워 둡니다. 화투 그림은 Wikimedia Commons의 [SVG Hwatu](https://commons.wikimedia.org/wiki/Category:SVG_Hwatu)(Spenĉjo · Marcus Richert · Louie Mantia, Jr., CC BY-SA 4.0)를 쓰며 출처는 `public/assets/hwatu/CREDITS.txt`와 게임설명에 적어 두었습니다.

**사보타지**는 3~10명이 하는 숨은 역할 게임입니다(AMIGO Saboteur 기본판 규칙). 라운드마다 역할을 비밀리에 받아 광부는 시작 카드에서 7칸 떨어진 목적지 3장(금 1·돌 2) 중 금까지 굴을 잇고, 방해꾼은 몰래 막습니다. 인원별 방해꾼/광부는 3명 1/3, 4명 1/4, 5명 2/4, 6명 2/5, 7명 3/5, 8명 3/6, 9명 3/7, 10명 4/7이며(역할 카드는 인원+1장), 손패는 3~5명 6장, 6~7명 5장, 8~10명 4장입니다. 카드는 길 40장(막다른 길 9장 포함)과 행동 27장(도구 부수기 9, 고치기 9, 지도 6, 낙석 3)입니다. 차례마다 길 카드를 놓거나 행동 카드를 쓰거나 한 장을 버리고 패스한 뒤 한 장을 뽑으며, 도구가 하나라도 부서지면 길 카드를 낼 수 없습니다. 광부 팀과 방해꾼 팀이 한 판으로 겨루는 팀전입니다(원작은 3라운드 동안 금 카드를 나눠 가짐). 누구든 길이 금 목적지에 닿으면 광부 전원이 이기고, 카드가 모두 떨어질 때까지 금을 못 찾으면 방해꾼 전원이 이기며, 랭킹에는 이긴 팀 전원이 승리로 기록됩니다(Elo). 차례 60초가 지나면 첫 손패를 버리고 패스하며, 카드 그림은 원작 분위기를 따라 SVG로 새로 그렸습니다(`public/saboteur-art.js`).

**관전**으로 경기 중인 방에도 입장할 수 있습니다. 방에서 참가자와 관전자 이름을 확인할 수 있습니다. 참가자는 언제든 **관전석으로 이동**할 수 있고, 빈자리가 있으면 관전자는 **참가하기**로 그 자리에 앉을 수 있습니다. 경기 중 빈자리가 생기면 그 자리에 누군가 앉을 때까지 경기가 멈춥니다. 경기 도중 다른 사람이 자리를 이어받은 판은 랭킹에 반영되지 않습니다.

## 로컬 실행

저장소 루트에서 Node.js 22 이상과 npm으로 실행합니다.

```powershell
cd Web
npm ci
npm run dev
```

`http://localhost:8787`에 접속해 로그인 창에서 **회원가입**을 선택하고 닉네임과 4자 이상의 비밀번호를 입력합니다. 예전에 발급받은 접속 키는 로그인 화면의 비밀번호 칸에서 계속 사용할 수 있습니다. 로컬 D1과 대전방 상태는 `Web/.wrangler`에 저장됩니다.

`npm run check`로 게임 규칙을 검증합니다. 개발 서버가 실행 중이면 별도 터미널에서 `npm run check:worker`로 가입, 대전 WebSocket, 차오차오 20초 자동 PASS, 랭킹 저장을 검증할 수 있습니다. 이 통합 테스트는 실행 중인 로컬 DB에 테스트 계정과 경기를 추가합니다.

## Cloudflare 배포

`Web`에서 실행합니다. 첫 배포에만 Wrangler 계정 연결과 D1 생성이 필요합니다. `--location=apac`은 D1 데이터베이스의 아시아 태평양 배치 힌트입니다.

```powershell
npm exec -- wrangler login
npm exec -- wrangler d1 create ddongvoid --location=apac --update-config=false
npm run deploy
```

이후 업데이트에는 `npm run deploy`를 사용합니다. 이 명령은 정적 자산을 준비하고 D1 마이그레이션을 적용한 뒤 Worker를 배포합니다.

배포 출력의 `workers.dev` 주소에서 접속할 수 있습니다. 커스텀 도메인을 쓸 경우 Worker의 **설정 → 도메인 및 경로**에서 Cloudflare에 등록된 도메인을 연결합니다.

GitHub 자동 배포에는 같은 Worker의 Workers Builds를 사용합니다. 운영 브랜치는 `codex/web-production`, 루트 디렉터리는 `Web`, 빌드 명령은 `npm run check`, 배포 명령은 `npm run deploy`로 설정합니다. 빌드 토큰에는 Workers와 D1 편집 권한을 부여합니다. 운영 데이터베이스는 운영 브랜치에서만 마이그레이션합니다.

## 배경음악

로그인한 이용자에게만 배경음악을 재생합니다. R2나 결제수단 등록 없이 기존 Workers 정적 자산에 MP3를 함께 배포합니다. 홈페이지 상단 플레이어에서 현재 곡과 가수를 확인하고 시작, 일시정지, 다음 곡, 재생 목록 선택과 볼륨 조절을 할 수 있습니다. 현재 시간과 전체 길이를 표시하고, 진행 막대를 움직여 재생 위치를 바꿀 수 있습니다. 볼륨 표시는 0~100%이며 첫 방문 기본값은 50%입니다. 실제 출력에는 0.15를 곱합니다. 여섯 곡을 순서대로 재생한 뒤 처음부터 반복하고, 선택 곡·볼륨·일시정지 설정은 브라우저에 기억합니다. 키보드 리듬 화면에서는 BGM이 자동으로 멈추고, 화면을 나가면 이전 재생 상태로 돌아옵니다. 브라우저 정책상 첫 클릭이나 시작 버튼을 누른 뒤 음악이 나올 수 있습니다.

`Web` 폴더에서 음원을 배포 자산에 복사한 뒤 배포합니다. 파일은 Git에서 제외됩니다.

```powershell
New-Item -ItemType Directory -Path public/api -Force
Copy-Item -LiteralPath "C:\경로\노래.mp3" -Destination public/api/music.mp3
npm run deploy
```

곡 목록은 `public/music-library.js`에서 관리합니다. 현재 배포하는 음원 파일은 다음과 같습니다.

| 곡 | 로컬 배포 파일 |
| --- | --- |
| Kelly Clarkson — Underneath The Tree | `public/api/music-files/underneath-the-tree.mp3` |
| Mariah Carey — All I Want For Christmas Is You | `public/api/music-files/all-i-want-for-christmas.mp3` |
| Post Malone — Circles | `public/api/music.mp3` |
| Ariana Grande — Santa Tell Me | `public/api/music-files/santa-tell-me.mp3` |
| 아이유 — 미리 메리 크리스마스 | `public/api/music-files/iu-merry-christmas.mp3` |
| Wham! — Last Christmas | `public/api/music-files/last-christmas.mp3` |

로컬 개발 서버에서도 같은 파일을 사용합니다. `/api/*`는 항상 Worker를 먼저 거치므로 음원 파일 주소로 직접 접근해도 로그인 검사를 통과해야 하며, 파일 자체는 `/api/music/곡ID`에서만 제공합니다. 기존 `/api/music` 주소는 Circles를 제공합니다. 바꾼 곡은 브라우저 캐시 때문에 최대 1시간 뒤에 반영될 수 있습니다.

음원을 유지하려면 이후 배포에도 위 MP3 파일을 모두 포함해야 합니다. GitHub 자동 배포에는 이 로컬 파일이 전달되지 않으므로, 자동 배포 후 음악이 사라지면 음원이 있는 로컬에서 다시 배포합니다. 필요하면 선택적으로 `MUSIC` R2 바인딩을 추가해 기존 R2 음원(`bgm`)을 Circles에 사용할 수도 있습니다.

## 웹 게임 상태

- Workers가 정적 화면, 로그인과 게임 API를 제공합니다.
- SQLite 기반 Durable Object가 방마다 게임 상태를 보존하고 WebSocket으로 변경을 알립니다. 이후 참가자가 조회하는 상태에는 자신이 볼 수 있는 정보만 포함됩니다. 브라우저를 닫았다 다시 접속해도 대전을 이어갈 수 있습니다.
- 대전 게임 랭킹은 게임별 점수 순입니다. 점수는 Elo 방식으로 계산합니다. 모두 1000점에서 시작하고(K=32), 점수가 높은 상대를 이기면 많이, 낮은 상대를 이기면 적게 오릅니다. 3~4인 게임은 승자가 패자 각각을 이긴 것으로 계산합니다. 단독 승리로 2연승 이상 하면 연승 보너스로 (연승 수 − 1) × 2점, 최대 10점을 더 받습니다. 연패에는 불이익이 없습니다. 자리를 이어받은 판과 둘 다 포기한 판은 반영하지 않습니다.
- 섯다는 점수 대신 돈으로 랭킹을 매깁니다. 모든 계정은 1,000만원에서 시작하고, D1의 `wallets`에 잔액과 파산 횟수를 저장합니다. 판이 끝나면 각자 딴 돈과 잃은 돈을 반영하고(판 도중 나간 사람 포함), 다음 판은 방이 D1에서 다시 읽은 잔액으로 시작합니다. 잔액이 10만원 이하이면 다음 판을 시작할 때 파산 처리하고 300만원으로 다시 채웁니다.
- D1이 계정과 세션, 방 목록, 랭킹을 저장합니다. 완료한 싱글 게임은 서버가 입력 기록을 재생해 점수를 계산합니다. 웹의 싱글 랭킹 한 판은 최대 30분입니다.
