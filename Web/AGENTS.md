# 웹 프로젝트 작업 지침

- 모든 코드 리뷰 결과와 사람이 읽는 리뷰 설명은 한국어로 작성한다.
- 배경음악, 자산, Cloudflare 설정 또는 배포 방식을 변경하기 전에 [MUSIC.md](MUSIC.md)를 읽고 해당 배포 규칙을 따른다.
- 사이트 `ddongvoid`와 비공개 음원 서비스 `ddongvoid-music-assets`의 독립 배포 구조를 유지한다. 일반 사이트 배포는 음원 파일을 요구하거나 음원 서비스를 갱신하지 않아야 한다.
- 음원 자체를 추가·교체하는 요청이 있을 때만 `npm run deploy:music`를 사용한다. 음원 파일 누락 검사를 우회하지 않는다.
