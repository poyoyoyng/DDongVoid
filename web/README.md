# 증윷 — 운을 던지고, 판을 바꾸다

일반 윷놀이에 세 번의 증강 선택을 더한 2~4인 개인전 웹 게임입니다. 각자 말 4개와 증강을 가지며 팀은 없습니다. 기존 Windows 앱과 독립적으로 실행합니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```bash
cd web
npm start
# 브라우저에서 http://localhost:3000
```

`PORT=8080 npm start`로 포트를 바꿀 수 있습니다. 같은 네트워크의 다른 기기에서는 `http://서버PC의IP:3000`으로 접속합니다. 인터넷 대전에는 이 Node 서버를 HTTPS를 제공하는 호스팅에 배포해야 합니다. 정적 파일만 배포하는 GitHub Pages에서는 온라인 방 API가 동작하지 않습니다.

- **AI와 한 판:** 총 2·3·4인 중 선택하고 나를 제외한 자리는 AI가 맡습니다.
- **같은 기기 대전:** 2·3·4인을 선택하고 각 이름을 입력해 번갈아 조작합니다.
- **온라인 초대:** 한 명이 방을 만들고 링크나 6자리 코드를 전달하면 최대 4명이 참가합니다. 방을 만들 때 정한 최대 인원 안에서 2명 이상 모이면 방장이 시작합니다. 시작한 뒤에는 새 참가자가 들어올 수 없습니다. 선공은 무작위이며 이후 참가 순서대로 돌아갑니다. 주사위와 규칙은 서버에서 처리합니다. 방 참가 토큰은 브라우저에 보관하며, 같은 브라우저에서 해당 코드로 재접속할 수 있습니다. 비공개 창·다른 브라우저에는 토큰이 없으므로 이미 찬 방에 재접속할 수 없습니다.

현재 방 상태는 **서버 메모리**에만 보관합니다. 서버 재시작 또는 마지막 요청 후 6시간이 지나면 만료됩니다. 다중 인스턴스 운영·영구 보관은 공용 저장소가 필요합니다. 실행 중인 방은 최대 500개입니다. 토큰을 갖고 있는 참가자만 상태를 읽거나 조작할 수 있습니다. 계정·랭킹·대전 매칭은 포함하지 않습니다.

플레이어 1·3은 왼쪽, 2·4는 오른쪽에 배치합니다. 2인전에서는 양쪽 위에 한 명씩 보이고 나머지는 빈 자리로 표시합니다. 윷 던지기, 결과 선택, 이동·알까기 조작, 행동 안내와 기록은 중앙에 모았습니다.

## 기본 규칙

- 말은 4개. 도·개·걸·윷·모는 각각 1~5칸이며 4개 윷의 앞뒤를 균등 확률로 뽑습니다. 빽도를 켜면 표시된 한 윷만 뒤집히는 경우가 빽도입니다. 확률은 도 3/16, 개 6/16, 걸 4/16, 윷 1/16, 모 1/16, 빽도 1/16입니다. 빽도를 끄면 도가 4/16입니다.
- 윷·모가 나오면 추가 던지기 1회. 결과를 모아서 원하는 순서로 쓸 수 있고, 추가 던지기 전에 이동해도 됩니다.
- 정확히 상대 칸에 도착하면 해당 묶음을 전부 잡고 한 번 더 던집니다. 윷·모 이동으로 잡으면 이미 얻은 기회와 중복 지급하지 않습니다.
- 내 말을 만나면 자동 업기. 업힌 묶음은 함께 이동하고 함께 잡힙니다.
- 오른쪽 위·왼쪽 위 모서리에서 **이동을 시작할 때** 지름길을 선택합니다. 지나치는 모서리에서는 꺾지 않습니다. 중앙에 멈췄으면 다음 이동 때 빠른 출구 또는 왼쪽 경유를 선택합니다.
- 빽도는 실제로 지나온 길을 되짚습니다. 첫 칸에서 뒤로 가면 대기로 돌아갑니다. 판 위에 말이 없으면 빽도를 소모합니다. 출발·도착 칸에서 앞으로 한 칸 더 나가야 완주합니다.
- 네 말이 모두 완주하면 기본 승리. 네 개 업기·일렬 배치는 해당 증강을 가진 사람만 추가 승리 조건입니다.

## 증강

각자 자신의 **5·10·15번째 턴 시작**에 3개 중 1개를 골라 총 3개를 가집니다. 추가 던지기는 같은 턴이므로 턴 수를 늘리지 않습니다. 같은 증강은 중복 제안하지 않습니다. 제안 전체를 다시 받는 기회는 **플레이어당 판 전체 1회**이며, 교체 전 카드와 다른 세 가지를 제안합니다. 등급은 효과 분류이며, 현재 모든 증강의 제안 확률은 같습니다.

| 증강 | 효과 |
| --- | --- |
| 사단 합체 | 판 위 한 칸에 내 말 4개를 업으면 즉시 승리 |
| 일렬횡대 | 그려진 직선 경로의 서로 다른 연속 4칸에 4개 배치 시 즉시 승리. 대기·완주 말은 제외 |
| 작지만 확실한 | 무작위 던지기 대신 도·개 중 직접 선택. 윷·모 없음 |
| 알까기의 달인 | 내 4의 배수 턴 시작에 한 발. 내 말과 한 명 이상의 상대 말이 판 위에 있을 때만 발동. 뒤로 당겨 발사하고 드래그 길이로 파워 조절. 명중 시 상대 묶음 잡기 + 보너스 던지기, 빗나가면 내 묶음 탈락 |
| 한 번 더 생각해 | 매 턴 1회, 도·개·걸·빽도 재던지기. 작지만 확실한과 결합하면 도·개 재선택 |
| 든든한 호신부 | 판 전체 2회, 일반 잡기·알까기 방어. 일반 잡기 공격자는 원래 위치 유지 |
| 세 번째 큰 걸음 | 내 3의 배수 턴의 첫 전진 이동 +1칸 |
| 추격 본능 | 잡을 때 다음 전진 +1칸, 최대 +2까지 누적. 사용한 뒤 새로 잡으면 새 보너스 유지 |
| 나 홀로 산책 | 업지 않은 말의 도 이동 +1칸 |
| 다시 출발 | 잡힌 말의 다음 대기 출발 +2칸, 출발 후 소모 |
| 앞으로만 | 빽도 → 도 |
| 완주의 기세 | 완주 시 추가 던지기, 턴당 1회 |
| 도파민장아찌 | 선택한 턴부터 내 7턴 동안 모든 전진 +1칸. 이후 영구 −1칸. 빽도는 그대로이며 0칸이 되면 정지 |
| 어쩌라고아줌마 | “어쩌라고!” 하며 잡기·알까기에 총 3회 면역. 묶음 전체를 보호하고 한 번의 공격에 1회만 소모 |
| 반찬맨 | 평소 도·개·걸, 드물게 모가 나오면 추가 던지기 2회. 윷·빽도 없음 |

도파민장아찌는 선택한 턴을 첫 번째로 세며, 예를 들어 5턴에 골랐다면 자신의 5~11턴에 +1, 12턴부터 −1입니다. 추가 던지기·잡기는 같은 턴이므로 기간을 줄이지 않습니다. 다른 이동 보너스와 합산한 전진 거리가 최소 0칸이며, 빽도에는 적용하지 않습니다. 어쩌라고아줌마와 호신부를 함께 가지면 면역 3회를 먼저 쓰고 호신부 2회를 씁니다. 면역으로 막힌 공격은 추가 던지기·추격 보너스를 주지 않습니다. 남은 기간·면역 횟수는 플레이어 카드에 표시합니다.

반찬맨의 모는 기본 모의 추가 던지기를 대체하여 **추가 2회**를 줍니다. 한 번 더 생각해로 재던져 모가 나와도 적용하며, 그 모로 말을 잡았다고 추가 기회를 중복 지급하지 않습니다. 던지기를 대체하는 작지만 확실한과는 함께 제안하지 않습니다.

알까기는 판 위의 내 알을 **뒤로 당겼다가 놓으면 반대 방향으로 날아가는 방식**입니다. 당긴 길이에 비례해서 파워와 비거리가 커지며, 조준선·고무줄·파워 게이지가 실시간으로 표시됩니다. 640×640 논리 좌표에서 드래그 8 미만은 취소, 180 이상은 최대 파워이며 최대 비거리는 760입니다. 마우스·터치 모두 판 밖으로 당겼다가 놓을 수 있습니다.

- 궤적에서 맨 처음 맞은 상대 묶음 전체가 튕겨 나가 대기로 돌아갑니다. 발사한 내 말은 원래 칸으로 돌아오고 보너스 던지기 1회를 얻습니다.
- 빗나가거나 파워가 부족해 상대에게 닿지 않으면 **발사한 내 묶음 전체가 날아가 탈락**하고 대기로 돌아갑니다. 자멸에는 내 호신부·면역을 쓰지 않으며, 다시 출발 증강의 재출발 보너스는 적용됩니다.
- 상대의 면역·호신부에 막히면 양쪽 묶음 모두 제자리에 남고 추가 던지기는 얻지 않습니다. 한 번의 공격에 방어 1회만 소모합니다.
- 발사·명중·탈락은 애니메이션으로 표시하고, 비행 중에는 다음 조작을 잠시 잠급니다. 온라인 참가자도 같은 발사 결과를 봅니다.
- 자동 조준 버튼은 없습니다. 키보드는 알을 선택한 뒤 좌우 방향키로 방향, 상하 방향키 또는 +/−로 파워, Space로 발사합니다. 짧은 탭·Escape·터치 취소는 발사나 탈락을 일으키지 않습니다. 건너뛰기를 누르면 일반 윷놀이를 계속합니다.

서버는 클라이언트가 보낸 드래그 벡터로 방향·파워와 충돌을 계산합니다. 별도로 보낸 임의의 `power` 값은 사용하지 않습니다. 충돌은 말의 반지름 21을 합산한 42를 기준으로 연속 궤적에서 계산하므로 빠른 발사도 상대 말을 통과하지 않습니다.

## 검증

```bash
cd web
npm test
```

Node 기본 테스트 러너로 확률 16경우, 이동 경로, 지름길, 빽도, 업기·잡기, 추가 던지기, 특수 승리, 증강 시점, 15종 효과, 알까기 충돌과 서버 인증·버전 충돌을 검사합니다. 2·3·4인 각각 60개, 총 180개 시드의 AI 대전이 종료되며 모든 말이 유효한 칸에 있는지도 검증합니다. `web.yml`에서 자동 실행합니다.

구성: `engine.mjs`는 브라우저·서버가 공유하는 규칙, `app.mjs`는 UI·AI·온라인 동기화, `server.mjs`는 정적 파일과 방 API입니다. 외부 패키지·CDN·폰트 요청이 없습니다.
